# Заметки по работе сети 

### 1. Локальный запуск (через терминал poetry run)
При запуске сервисов через `poetry run uvicorn src/app/main:app --host --port` они работают на одной машине. Используем `127.0.0.1:{порт}`.

### 2. Запуск в контейнере через 127.0.0.1 (ломается)
Внутри контейнера `127.0.0.1` — это он сам. Сервисы друг друга не найдут.

### 3. Успешный запуск через имена сервисов (Docker)
В `docker-compose.yml` мы в одной сети. Пишем `http://product-service:8000`. Docker резолвит имя.

### 4. Использование host.docker.internal
Позволяет из контейнера обратиться к хостовой машине (например, если БД запущена локально).
